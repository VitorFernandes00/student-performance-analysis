# 📊 Student Performance Analysis

Exploratory data analysis of student performance using Python.
This project aims to identify patterns and factors that influence students' scores in math, reading, and writing.

---

## 🎯 Objective

Analyze a dataset of students to understand how different variables impact academic performance.

---

## 🛠️ Tools & Libraries

* Python
* pandas
* numpy
* seaborn
* matplotlib

---

## 📁 Dataset

The dataset contains information about students, including:

* Gender
* Race/Ethnicity
* Parental level of education
* Lunch type
* Test preparation course
* Math, reading, and writing scores

---

## 📊 Analysis Performed

* Data exploration (shape, null values, duplicates)
* Statistical summary
* Distribution analysis
* Comparison between groups (gender, education, test preparation)
* Correlation between scores

---

## 📈 Key Insights

* Students who completed the test preparation course tend to have higher scores
* Reading and writing scores show strong correlation
* Parental level of education impacts student performance
* Some variation in performance can be observed between genders

---

## ▶️ How to Run

1. Clone the repository
2. Install the required libraries:

```bash
pip install pandas numpy seaborn matplotlib
```

3. Run the script:

```bash
python analysis.py
```
